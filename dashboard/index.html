Central API Gateway

Gateway Architecture

Frontend → Cloudflare Workers API Gateway → Selected Backend Provider (Vercel / Railway / Render) → Database & Services. Safe fallback only executes for idempotent methods (GET, HEAD, OPTIONS). Non-idempotent requests (POST, PUT, PATCH, DELETE) are never automatically retried.

Secret values are always masked; internal credentials, passwords, tokens, private keys, and signing secrets are never displayed.
